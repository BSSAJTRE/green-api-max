# Локальный запуск с эмулятором

Чат работает с локальным эмулятором GREEN-API. Учётная запись MAX и доступ в личный кабинет GREEN-API не нужны: эмулятор принимает любые `idInstance` и `apiTokenInstance`.

## Требования

- Node.js `^20.19.0` или `>=22.12.0`
- npm

## Установка

В корне проекта:

```bash
npm install
```

## Запуск

Нужны два терминала. Сначала эмулятор, затем приложение.

**Терминал 1 — эмулятор GREEN-API**

```bash
npm run emulator
```

Эмулятор слушает `http://localhost:3001`. Панель управления открывается по тому же адресу: [http://localhost:3001/](http://localhost:3001/).

Порт можно сменить переменной окружения `EMULATOR_PORT`. Если порт не `3001`, тот же адрес нужно указать в `.env.emulator` в `VITE_GREEN_API_URL`.

**Терминал 2 — приложение**

```bash
npm run dev:emulator
```

Скрипт запускает Vite в режиме `emulator` и подхватывает `.env.emulator`: запросы уходят на `http://localhost:3001`. Приложение открывается по адресу, который Vite напечатает в терминале, обычно [http://localhost:5173/](http://localhost:5173/).

На экране входа будет заметка, что запросы идут на локальный эмулятор.

## Вход и переписка

1. Откройте приложение и введите любые данные, например `idInstance` `3100000001` и `apiTokenInstance` `token`. `idInstance` — только цифры, не длиннее 12 символов.
2. После входа уже есть демонстрационные чаты: Анна (`+7 999 111-22-33`), Иван (`+375 29 123-45-67`) и чат с перепиской за три дня (`+7 999 444-55-66`).
3. Новый чат создаётся по кнопке нового чата. Подойдёт любой номер России или Беларуси. Номер, который оканчивается на `0000`, эмулятор считает незарегистрированным в MAX.
4. Отправленное сообщение получает статусы «доставлено» и «прочитано». Если включён автоответ, через несколько секунд приходит ответ контакта.

Состояние эмулятора хранится в памяти процесса и пропадает после его остановки. Сессия приложения сохраняется в `localStorage` браузера. После перезапуска эмулятора войдите с тем же `idInstance`, чтобы снова увидеть демонстрационные чаты, либо очистите данные сайта в браузере.

## Панель эмулятора

Панель на [http://localhost:3001/](http://localhost:3001/) показывает инстанс, с которым последним работало приложение.

- **Автоответ контакта** — отвечает на исходящие сообщения. По умолчанию включён.
- Список контактов — переписка этого инстанса. Выберите контакт и напишите сообщение: оно придёт в приложение как входящее.
- **Добавить контакт** — телефон в международном формате без `+`, например `79991234567`, и необязательное имя. Чат появится в приложении после входящего сообщения от этого контакта или когда тот же номер найдут через «Новый чат».

Оба процесса останавливаются через `Ctrl+C` в соответствующем терминале.
